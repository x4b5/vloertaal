# Mails voor de pilot

Antwoorden op wie reageert op het LinkedIn-bericht. Vul `[CODE]` zelf in. De code staat nergens in
deze repo en hoort daar ook niet: geef hem alleen per bericht.

Houd per persoon bij wie de code kreeg en wanneer (een lijstje is genoeg). Dan weet je wie je na een
week een bericht stuurt (mail 5).

---

## 1. Iemand wil de app proberen

**Onderwerp:** Je toegangscode voor Vloertaal

Hoi [naam],

Leuk dat je Vloertaal wilt proberen! Je toegangscode is: **[CODE]**

Zo begin je:
1. Open **vloertaal.nl** op je telefoon. De app is gemaakt voor de telefoon. Op een computer werkt hij
   ook, maar dan zie je hem smal.
2. Kies een hulptaal. Wil je zien hoe het voor een leerling is? Kies dan een taal die je niet kent.
3. Vul de code in als de app erom vraagt.
4. Doe een paar lessen. Zet het geluid aan: alles wordt voorgelezen.

Tip: je kunt de app op je beginscherm zetten. In de app staat hoe dat moet, bij Instellingen.

Geef de code alsjeblieft niet zelf door. Wie hem ook wil hebben, kan mij mailen. Zo weet ik wie
meedoet.

Over een week stuur ik je een korte mail met een paar vragen. Zie je eerder iets wat niet klopt?
Stuur dan gerust meteen een schermfoto.

## 3. Expert arbeidsrecht, vakbond of Juridisch Loket

**Onderwerp:** Vloertaal: meekijken naar de uitleg over regels en rechten

Hoi [naam],

Dank je wel dat je wilt meekijken. Je toegangscode is: **[CODE]**. Open **vloertaal.nl** op je
telefoon, kies een hulptaal en vul de code in.

In de taallessen staan korte tips over hoe het werkt op de Nederlandse werkvloer: ziekmelden,
loonstrook, proeftijd, veiligheid. Klopt wat daar staat? Is er iets wat te kort door de bocht is?

Er is ook een apart deel, **Werkregels**: uitleg in eenvoudig Nederlands over geschreven en
ongeschreven regels, voor mensen die al Nederlands spreken. Dat deel staat nog uit. Ik zet het pas
aan als een deskundige het heeft nagekeken. Wil je daarnaar kijken? Dan stuur ik je de inhoud als
document, met per punt de bron. De punten die ik niet zeker weet, staan apart.

Ook als je maar een deel kunt nakijken, help je me al veel.

Ik heb twee vragen:
1. **Doe een paar lessen** en let op de teksten in het [taal]. Klinkt iets vreemd, onbeleefd,

## 5. Na een week

**Onderwerp:** Vloertaal: hoe ging het?

Hoi [naam],

Een week geleden kreeg je de code voor Vloertaal. Hoe ging het? Je mag op deze mail antwoorden met
korte antwoorden, ook als je de app maar één keer hebt geopend.

1. Hoe vaak heb je de app geopend, ongeveer?
2. Wat was fijn, en wat was lastig of onduidelijk?
3. Klopte er iets niet, in de taal, de vertaling of de uitleg?
4. Zou je de app aanraden aan iemand die je kent, zoals een leerling, collega of cliënt? Waarom wel
   of niet?

Dank je wel voor je tijd!

Groet,
[jouw naam]
Vloertaal · hoi@vloertaal.nl
