# Contacten

Wie is benaderd, en wat is de volgende stap? **Zonder namen**: deze repo is openbaar. Elke regel
heeft een code. Wie achter een code zit, houdt Xavier zelf bij, buiten de repo (een lijstje op zijn
eigen telefoon of computer is genoeg).

De secretaris vult dit in als Xavier het zegt, bijvoorbeeld: "C-03 is een taalhuis, link gestuurd
op 14 november". Een agent benadert zelf niemand.
